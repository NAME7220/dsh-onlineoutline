# dsh-onlineoutline

[English](README.md) | **简体中文**

DeepSeek Harness 对话右侧的**可滚动提问大纲**。它替换内置的轮次刻度轨，列出这个会话里的每一个提问，方便你随时看清自己在哪，并跳回任意一轮。

> **非官方插件。** 这是社区插件，不是 DeepSeek 官方发布，与 DeepSeek 无隶属或背书关系。
>
> **与 DSH 同等权限运行。** DSH 插件不在沙箱中：它运行在 harness 进程内，拥有与主程序相同的文件与进程访问权限。安装前（包括任何 fork 版本）请先阅读源码。
>
> **仅锁一个 DSH 版本。** 仅针对 DeepSeek Harness `0.2.2-rc.5` 编写并验证。它读取了内置的 DOM 标记和一个哈希类名，因此 DSH 升级后大概率会失效，详见下文「环境要求与已知限制」。

已在 **DeepSeek Harness `0.2.2-rc.5`**（Windows 桌面端）上开发并验证。

## 功能

- **收起态**：右边缘一条细刻度带 —— 每一轮一根灰色胶囊，当前正在读的那一轮是亮蓝色。没有文字、没有滚动条、没有边框。
- **悬停 / 键盘聚焦**：立刻展开成 240px 面板，列出全部提问，每行带轮次号、单行标题和一根刻度。
- **悬停预览**：行左侧弹出 300×100 卡片，显示完整提问和回答开头，样式对齐内置预览。
- **点击某行**：对话滚动到该轮。
- **不会横向跳动**：刻度与文字右对齐，两种状态下都预留滚动条槽位，展开时没有任何水平位移。
- **空间不足时让位**：面板与消息列的间距小于 18px，或对话区宽度低于 420px 时自动隐藏（带迟滞，不会闪烁）。
- **窗口缩放**：宽度低于 1080px 时自动收起左侧会话栏给对话腾地方，高于 1220px 时还原。点击后会复核并重试，因为大幅重排期间单次程序化点击有时会被吞掉。

只用三种颜色：静止灰、悬停白、当前轮亮蓝。

## 安装

bundle 就是一个普通目录，没有构建步骤。

从 GitHub 直接安装：

```bash
dsh plugin --profile desktop add github:NAME7220/dsh-onlineoutline
```

或克隆到本地后按路径安装：

```bash
git clone https://github.com/NAME7220/dsh-onlineoutline.git
dsh plugin --profile desktop add <本目录绝对路径>
```

也可以在 DeepSeek Harness 的插件管理里，用 `install_bundle` 指定本目录的绝对路径。

装完刷新窗口；若客户端模块已被缓存，重启一次桌面端。

## 环境要求与已知限制

- 依赖 `conversation.composer.dock` 插槽和 `turnOutline` 会话投影，两者都由 `@deepseek-ai/dsh-client-ui-chat` 提供。
- 三处与内置产物的耦合（`client.js` 里都有标注），DSH 升级后都可能失效：
  - `.SNx2jG_frame` —— 本插件隐藏的内置轨道哈希类名；
  - `[data-turn-tail]` —— 每轮尾部标记，用于跳转、判断阅读位置、测量列宽；
  - `[data-sidebar-toggle]` —— 用于折叠左侧栏的按钮。
- 提问为空的轮次（例如纯图片消息）显示为 `#<轮次号>`。

## 布局常量

可调参数都在 `client.js` 顶部：面板宽度与最大高度、收起带宽度、右侧偏移、与消息列的最小间距，以及左侧栏行为的两个视口阈值。
